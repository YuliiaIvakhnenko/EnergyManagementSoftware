# Лабораторна робота №1 — Проектування системи збереження та збору даних

**Дисципліна:** Програмне забезпечення енергетичного менеджменту  
**Варіант:** 3 — Лабораторія, Київ, 2025  
**Трек:** А — реляційна система

## Що реалізовано

- Нормалізована SQLite-БД для трирівневого енергомоніторингу.
- Таблиці об'єктів, лічильників, погодинних вимірювань, метеоданих, тарифів, baseline.
- Індекси, зовнішні ключі, обмеження цілісності.
- Представлення для рівнів обліку 1, 2, 3.
- Генератор реалістичних погодинних даних за 2025 рік: `8760 × 7 = 61 320` вимірювань.
- Аналітичні SQL-запити та CSV-результати.

## Структура

```text
src/
  config.py          # параметри варіанта 3
  database.py        # створення БД і виконання schema.sql
  generate_data.py   # генерація тестових даних
  analytics.py       # аналітичні запити та результати
sql/
  schema.sql         # DDL, індекси, views
  queries.sql        # приклади аналітичних запитів
outputs/
  energy_lab1_v3.sqlite
  analytics_results/*.csv
  diagrams/schema.mmd
  diagrams/schema_diagram.png
```

## Як запустити

```bash
python -m venv .venv
source .venv/bin/activate      
pip install -r requirements.txt
python src/generate_data.py
python src/analytics.py
```

Після запуску база буде створена в `outputs/energy_lab1_v3.sqlite`, а результати SQL-аналітики — у `outputs/analytics_results/`.
